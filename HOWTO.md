# Как это всё завести

1. Создай на GitHub репозиторий с именем **ровно как твой юзернейм**:
   `nanodev1488/nanodev1488` (важно: имя репо = имя юзернейма).

2. Залей туда всё содержимое этой папки (README.md, .github/, scripts/, assets/).

3. Положи своё фото в `assets/photo.jpg` (замени плейсхолдер).

4. В README замени в ссылках на бейджи/змейку `nanodev1488` — уже подставлено,
   но перепроверь, что совпадает с твоим реальным юзернеймом.

5. Ничего дополнительно настраивать не нужно — `GITHUB_TOKEN` для Actions
   создаётся автоматически GitHub'ом, вручную секреты добавлять не надо.

6. Зайди в **Settings → Actions → General → Workflow permissions**
   и выбери **Read and write permissions** — иначе экшены не смогут
   пушить коммиты и снейка.

7. После первого пуша зайди во вкладку **Actions** и запусти вручную
   (`workflow_dispatch`) оба воркфлоу: `Generate Snake` и `Update README`,
   чтобы не ждать расписания.

8. Через пару минут снейк появится на ветке `output`, а секция про
   nano-decompiler в README подтянет актуальные звёзды/язык/коммит —
   если репозиторий `nano-decompiler` у тебя публичный на этом же аккаунте.
